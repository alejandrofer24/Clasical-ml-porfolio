# Data

Datasets are **not** committed. Download them and place them in this folder:

| Notebook | Files | Source |
|---|---|---|
| `01_heart_disease_ensembles.ipynb` | `heart.csv` | Heart Disease dataset (918 patients, target `HeartDisease`); public on Kaggle (*Heart Failure Prediction*) / UCI. |
| `02_gender_svm_kernels.ipynb` | `gender.csv` | Gender classification from facial measurements; provided in the course, public versions on Kaggle. |
| `03_spanish_names_gender_classifier.ipynb` | `male_spanish_names_reduced.csv`, `female_spanish_names_reduced.csv`, `test_dataset.csv` | Lists of Spanish first names by gender, provided in the course. |
| `04_titanic_survival_leakage_free.ipynb` | `titanic_train.csv`, `titanic_test.csv` | Titanic passenger data (course version, public equivalents on Kaggle / OpenML). |

`data/processed/` is created by the Titanic notebook for intermediate files and is git-ignored.
